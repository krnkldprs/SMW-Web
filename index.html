M Super Mario World Web

El clásico de SNES, corriendo en tu navegador con WebAssembly.

Pulsa Start Game y haz clic dentro del juego para capturar el teclado. En móvil aparecen los controles táctiles automáticamente.

Controles (teclado)

  • ↑ ↓ ← → Mover a Mario
  • Z Saltar (B)
  • X Correr / girar (A)
  • A Y
  • S X
  • Enter Start (pausa)
  • V Select
  • Q / E L / R

También funciona cualquier mando compatible (XInput).

Cómo funciona

Esta página no es una recompilación del juego: es un emulador de SNES (snes9x) compilado a WebAssembly mediante EmulatorJS, que carga la ROM. El guardado usa el almacenamiento del navegador.

Mete tu propio ROM en rom/super-mario-world-usa.sfc o cámbialo en index.html (variable EJS_gameUrl).
